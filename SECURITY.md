# Security

Tally is an unaudited reference implementation with no supported live deployment.
Passing tests do not approve production use or the accounting policy.

Report suspected vulnerabilities privately to the repository maintainers through
the channel used to share this repository. If none exists, ask a maintainer to
establish one before sending confidential details. Include the commit, affected
integration and a minimal local reproduction. Do not post credentials or exploit
details publicly. No bounty or response-time guarantee is advertised.

Production use requires independent security/accounting review and tested
permissions, valuation, reconciliation and recovery procedures. Keep RPC secrets
out of version control and unreviewed PR workflows. CI credential scanning is a
bounded pattern check, not proof that all sensitive content has been detected.
